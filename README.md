# Rick and Morty Explorer

A simple and responsive web app built with **React** and **Vite** that consumes the [Rick and Morty API](https://rickandmortyapi.com/) to display characters, episodes, and locations from the show.

![screenshot](./preview.png)

**🔗 Live Demo:** [https://felipecardosovargas.github.io/ricky-morty/](https://felipecardosovargas.github.io/ricky-morty/)

## Features

- Browse and filter **characters** by name, status, species, or gender  
- View details for **episodes** and **locations**  
- Fast performance with **Vite**  
- Fully responsive layout  
- Pagination and smooth loading  
- Clean and modern UI

## Technologies Used

- **React**
- **Vite**
- **Axios**
- **React Router DOM**
- **CSS Modules / Tailwind (optional)**
- [Rick and Morty API](https://rickandmortyapi.com/)

## Installation

```bash
# Clone the repo
